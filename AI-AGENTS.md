contribute to this repository.  Under no circumstances should a large
language model select an issue to solve in this repository without direct
human instructions to solve that specific issue.  Under no circumstances

individual pull requests and for the ecosystem as a whole.  If you didn't
bother writing it, we won't bother reading it.
